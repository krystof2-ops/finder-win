# Security Policy

## Supported versions

Only the latest release is supported. Please update to the newest version before reporting an issue.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately via
[GitHub Security Advisories](https://github.com/krystof2-ops/finder-win/security/advisories/new).

You can expect a first reply within a week. Finder-Win is a hobby project maintained by one person,
so fixes may take longer than in a commercial product.
